# 강의노트 합치기

강의 슬라이드 PDF와 전사 필기 PDF를 합쳐서, **A4 가로 한 장의 왼쪽엔 슬라이드,
오른쪽엔 그 장의 필기 전문**이 오는 PDF를 만듭니다.

## 바로 쓰기

**https://jnsungp.github.io/lecture-notes/**

계정도 설치도 필요 없습니다. 주소만 열면 됩니다.

1. 위 칸에 강의자료 PDF 한 개, 아래 칸에 전사 필기 PDF들을 넣습니다.
2. `PDF 만들기` 를 누르면 완성본이 내려받아집니다.

**강의자료의 모든 장이 들어갑니다.** 전사본이 다루지 않은 장은 오른쪽이 빈칸으로
나갑니다. 필기는 그 슬라이드 바로 옆에 놓이고, 한 칸을 넘치면 같은 슬라이드를 다시
놓고 `(이어서)` 로 잇습니다. 슬라이드 그림 아래에도 쪽 번호가 찍힙니다.

글자 크기·줄 간격·여백은 화면에서 조절할 수 있고, 필기를 오른쪽 칸에 촘촘히
이어 붙이고 싶으면 **필기 배치**를 바꾸면 됩니다.

**넣은 PDF는 어디로도 전송되지 않습니다.** 브라우저 안에서만 읽고 만듭니다.
한 번 열린 뒤에는 인터넷을 꺼도 그대로 동작합니다.

## 전사본 조건

본문 어딘가에 **한 줄로 떨어진 페이지 표시**가 있어야 슬라이드와 짝지을 수 있습니다.
아래 형태를 모두 알아봅니다.

```
Page 3                      page 3 / p.3 / p 3
Page 3 ( ~5:34)             뒤에 강의 시간이 붙어도 됩니다
1page                       12쪽 / 12 페이지 / 슬라이드 12
- 18 페이지 -                앞뒤 장식이 있어도 됩니다
(대장질환 병리 족첵본 77p.)    괄호로 감싼 짧은 안내 줄
```

글자를 선택해 복사할 수 있는 PDF여야 합니다. 스캔한 그림만 있는 PDF는 읽을 수 없습니다.
